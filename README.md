## 📖 About

Islamic Civilization Health System (ICHS) is an open educational project that explores healthcare from the perspective of Islamic civilization.

This repository integrates:

- 🕌 Islamic Worldview
- 🧠 Mental Health
- ❤️ Healthcare Policy
- 🏥 Bimaristan
- 📚 Medical History
- 🌍 Public Health
- 📖 Maqasid al-Sharia
- 🔬 Islamic Medical Civilization

The objective is to provide structured educational resources for students, researchers, educators, and anyone interested in Islamic civilization and healthcare.
